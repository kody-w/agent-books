C.2 Avoid false equivalences

A description is selection guidance, not proof of permission. A skill is not merely a schema-less substitute for every executable tool. A transcript view is not the full archive. Discovery of an existing definition is not creation of an implementation. A session fork is not byte-identical model replay. Prompt caching is not durable memory. A portable interface is not proof that all hosts provide the same dependencies.

The teaching examples make their execution locations explicit so these distinctions can be tested rather than settled by terminology.

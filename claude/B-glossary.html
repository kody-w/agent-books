Appendix B — Glossary

In this chapter: distinguish product terms from the book's application conventions.

B.1 Execution vocabulary

TermMeaning
Client toolA declared operation executed by your application.
Server toolAn operation executed by Anthropic, such as code execution or tool search.
tool_useAssistant content block requesting a client operation.
tool_resultUser content block returning the corresponding operation's result.
input_schemaJSON Schema describing a tool's argument shape.
Tool choiceRequest policy controlling automatic or named tool selection.
Programmatic tool callingCode in the execution container calls permitted tools and processes results.
Tool searchOn-demand discovery of definitions supplied in a tool catalog.
MCPTool connection protocol used by Code, the SDK, and product-specific connectors.
SDK MCP serverIn-process tool server created by the Agent SDK application.

These are documented tool and SDK concepts. Tool use, programmatic calls, search, SDK custom tools.

B.2 Organization vocabulary

TermMeaning
SkillReusable instructions and resources loaded when relevant or explicitly invoked.
FrontmatterYAML metadata at the start of a skill or subagent file.
SubagentDelegated assistant with its own context, instructions, and tool configuration.
HookLifecycle handler, possibly returning a structured decision.
PluginPackage of skills, agents, hooks, servers, or other supported components.
CLAUDE.mdStanding contextual instructions for a user, project, or organization.
Auto memoryNotes Claude Code accumulates from working context and corrections.
ProjectHost workspace carrying knowledge and instructions; rollout affects its exact behavior.

Skills, subagents, hooks, plugins, Code memory, Projects.

B.3 State vocabulary

TermMeaning
Memory toolClient-owned persistent file operations under a virtual memory directory.
Prompt cacheReused computation over matching prompt prefixes, not durable notes.
Context editingSelective removal of old content from the model's presented context.
CheckpointSession recovery point with specific file-tracking limits.
ResumeContinue a selected saved conversation.
ForkCreate a new session from a saved conversation while preserving the original.
Step replayBook convention: re-execute one recorded pure application handler.
data_slushBook convention: exact structured values passed downstream without paraphrase.

Memory, caching, context editing, checkpointing, sessions.

B.4 Failure vocabulary

Application guidance: distinguish authentication failure, incomplete model response, invalid arguments, handler refusal, exact-evidence mismatch, and missing executor. A final paragraph does not prove that the intended tool ran. An import check does not prove live account access. A context summary does not prove filesystem rollback.

B.2 Failure vocabulary

An unknown tool is a registry failure. A missing argument is a call-shape failure. An empty transcript is a domain refusal. A corrupt store is an execution failure. A source digest mismatch is a replay refusal.

A selection failure occurs when a model chooses the wrong capability. The miniature caller cannot exhibit or measure that failure because names are selected explicitly. A quality failure occurs when an artifact is misleading, unhelpful, or unsupported even though its structure and transport were valid.

These categories are intentionally separate. Repairing a schema will not fix an unauthorized backend, and increasing a model's context will not make a corrupt archive accurate.
